# After the Pull Request

A talk on the history of version control, from punch cards to pull requests, and what comes next.

**Live slides:** https://blackgirlbytes.github.io/after-the-pull-request/

## Controls

- `→` / `Space` / swipe: next slide · `←`: previous
- `P`: open the presenter view (talk track, next slide, timer), synced with the audience window
- `E`: edit text inline · `Cmd/Ctrl+S`: download the edited deck
